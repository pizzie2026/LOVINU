# LOVINU Website V1 – echte responsive Homepage

Dies ist kein Screenshot-Prototyp, sondern ein Next.js/React/TypeScript-Projekt.

## Lokal auf dem Mac starten
1. Ordner entpacken.
2. Terminal im Projektordner öffnen.
3. `npm install`
4. `npm run dev`
5. Im Browser `http://localhost:3000` öffnen.

## Responsive testen
Browserfenster schmal ziehen oder in Safari/Chrome die Responsive/Device-Ansicht verwenden. Das Layout hat eigene Desktop-, Tablet- und Smartphone-Regeln.

## Stand V1
- echte HTML-Texte, Links und Buttons
- responsive Navigation
- Desktop/Tablet/Mobile Layout
- Original-LOVINU-Logoassets
- Original-Teamfotos
- gemeinsame Komponentenlogik im Seitenaufbau
- SEO-Metadaten
- keine Datenbank nötig

Hinweis: Das Home-Hero-Foto und das Motiv „Wie gut kennst du dich?“ wurden für diesen ersten Browser-Prototyp aus dem abgestimmten Home-Referenzlayout ausgeschnitten, weil die separaten Originaldateien im Arbeitsordner nicht vorlagen. Sobald diese Originalbilder vorliegen, werden nur die Dateien in `public/images` ersetzt; Layout und Responsive-Code bleiben unverändert.
